The authoritative `suites/catalog.json` declares **164 scenarios across 22 suites**: 151 numbered shell/JavaScript entrypoints, eleven CSD browser scenarios and two standalone benchmarks. Stable IDs below are receipt identities, including two legacy IDs retained for DVWA payload history. They do not establish functional qualification.

Preview the full inventory without reading configuration, writing results or sending traffic:

```bash
bash suites/runner.sh catalog --dry-run
```

Use [Runner](../06-runner/) and [Continuous catalog](../continuous-catalog/) for installed operation, pacing
and native outcomes. The [DVWA mapping](../dvwa-payload-mapping/) preserves all 15 SQLi and 18 XSS payloads
against native authenticated DVWA; DemoApp is not an application coverage claim. [Native tool
audit](../native-tool-remediation/) retains failures and qualification limits. The AWS deployment
independently supports the canonical eleven-scenario CSD suite and its own browser/upload contract.

attempts and native reports. Slow-header execution uses actual OpenSSL clients. Load and benchmark phases use
native wrk, hey, Vegeta, ab, cURL and declared Lua phases with resource sampling and observed worker cleanup;
complete phase/content/host comparison acceptance remains open. Subfinder performs passive discovery of the
approved root; discoveries are not scanned.

CSD loaders fetch pinned executable library assets from the owned origin and assert library identity, behavior
and cleanup. Browser test doubles are source checks only. FFmpeg encodes real synthetic media and FFprobe
checks it; upload/conversion dispatch without complete native postconditions remains unqualified. All tool
dependencies must be present; silent substitutes or fabricated authentication/results cannot qualify
execution.

Fourteen scenarios currently declare functional contracts; 150 do not. Source execution contracts cover every entry, but full installed catalog acceptance requires every functional contract, actual reports/content, fixture recovery and independent control attribution.
